Table: `headerHeight` gives the header row its own height in px, such as 36 over 44px rows (`rowHeight` alone still sets both). It sets the new `--sui-table-header` token, which an app can also set itself.

Tag: a pressable Tag takes `size="sm"`, 22px tall with 12px text, for a dense row of filters; `md` (28px) stays the default.
