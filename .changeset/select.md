`Select`, a single choice from a short list: a bordered trigger in two sizes (`size` `md`, 36px for forms, or `sm`, 28px for table feet) and a list styled like menus, with the choice ticked. Bind it with `v-model` and pass `options` (`value`, `label`, optional `disabled`); `placeholder` (`Select an option`), `side` and `disabled` are optional. Attributes such as `id`, `aria-label` and a width class go to the trigger. For search, multiple choice or creating options, use `SelectInput`.
