`ImageInput`: a round (or `square`) preview that opens the file picker or takes a dropped PNG or JPG, with Upload, Replace and Remove. `v-model:image` holds the file and `v-model:image-url` the preview; it emits `change` and `remove`, and revokes the preview URLs it makes. `size`, `hint`, and translatable `label`, `uploadLabel`, `replaceLabel` and `removeLabel`.
