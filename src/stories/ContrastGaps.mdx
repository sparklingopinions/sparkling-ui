# Contrast gaps

The default colours are MustLoop's, kept as they are so the extraction changes nothing on screen. Some text pairs fall short of WCAG AA: 4.5:1 for normal text, 3:1 for large or bold text of 18.66px and up.

A story that shows one of them turns off only axe's `color-contrast` rule, with a comment naming the pair; every other rule still fails the test. Fixing a gap is a design change: agree it first, then change the token defaults and drop the story exceptions.

The ratios below are computed from the current theme, in both modes; switch the toolbar's theme to see another app's.
